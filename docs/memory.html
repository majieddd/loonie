Grounded Memory

A model-agnostic substrate for recursive self-improvement, and why a memory system is a self-improvement loop whether or not you meant it to be.

Synthesis · drawn from seven works on recursive self-improvement, quality-diversity search and backtest overfitting
Written against a working system whose measurements are cited throughout
Abstract

Memory systems for language models are usually designed as retrieval problems: store text, embed it, fetch the nearest neighbours. We argue this framing hides the fact that a memory system is a recursive self-improvement loop — it accumulates experience and changes future behaviour — and therefore inherits every failure mode the RSI literature has catalogued. We transfer four of those failure modes onto memory, show that three of them are invisible under standard retrieval metrics, and derive five invariants that a memory substrate must satisfy to avoid them. The invariants imply a specific architecture: provenance-carrying, model-agnostic records whose utility is scored by a process that did not write them, and deflated by the number of memories that were tried. Because the substrate is text-and-structure rather than one model's vector space, the same memory is readable by any local or cloud model without re-embedding or migration. We give the record schema, the scoring protocol, an evaluation design that would falsify the whole thing, and the failure modes we expect to survive it.

01The unacknowledged loop

A memory system writes something down because it seemed useful, then retrieves it later to change what the model does. That is a loop in which the system's own past output becomes its future input — which is the definition the RSI literature uses for self-improvement, and it does not stop being one because we called it retrieval.

The 2026 survey of 1,250 self-improvement papers states the governing constraint in a single sentence:

Every self-improvement loop is a claim that some signal can substitute for human judgment, and the loop's ceiling is exactly the quality of that substitute. Recursive Self-Improvement in AI: From Bounded Self-Refinement to Autonomous Research Loops, 2026 [1]

For a memory system, the substitute signal is "this is worth remembering." Almost every deployed system produces that signal from the same model that generated the content, at the moment of generation, with no outcome yet observed. The survey has a name for this arrangement, and it is not a compliment.

02Four failure modes, transferred

The survey identifies three collapse dynamics; the finance literature adds a fourth that applies whenever you select from many candidates. Each transfers onto memory cleanly, and three of the four are invisible to recall@k.

failure mode in self-improvement in a memory system
Self-confirming loop “when generator and evaluator share weights, biases correlate” — confidence-coupled rewards “over-reward high-confidence mistakes” [1] The model that wrote the memory also judges it worth keeping. Its confident errors are preserved preferentially, because confidence is what triggered the write.
Model collapse “if the fraction of exogenous, externally grounded signal vanishes asymptotically, degenerative dynamics follow” [1] Summaries of summaries. Each compaction pass replaces observation with the model's paraphrase of observation, and the exogenous fraction decays toward zero without any alarm firing.
Diversity collapse “proposers converge to the narrow band of problems that satisfy the reward, starving the solver's curriculum” [1] Retrieval returns what it returned last time, that context produces similar output, which produces similar memories. The effective context narrows while recall@k improves.
Selection bias “not controlling for the number of trials involved in a particular discovery leads to over-optimistic performance expectations” [7] A memory kept because it “worked once” was selected from every memory that could have been kept. With enough candidates, some look useful by arithmetic alone.

The third is the one worth dwelling on, because it is the only failure mode that improves your metrics as it gets worse. A memory system that has collapsed onto a narrow band retrieves highly relevant results with high confidence. Recall is excellent. It has simply stopped being able to surprise you, and nothing in a retrieval benchmark measures that.

03Five invariants

Each follows from a failure mode above, and each is a property you can check mechanically rather than a practice you have to remember.

I

Every record carries its ground truth, not a paraphrase of it

A memory stores the artefact — the command and its exit code, the diff, the test output, the measured value — and the model's interpretation as a separate, clearly-marked field. Compaction may rewrite the interpretation. It may never rewrite the artefact. This makes the exogenous fraction a structural property rather than a hope, which is what closes model collapse: the grounded portion cannot decay because nothing is permitted to overwrite it.

II

The writer and the scorer are different processes

Whatever decides a memory was useful must not be the thing that produced it. The cheapest sufficient separation is time: score a memory by what happened after it was retrieved, not by how confident the model was when it wrote it. Retrieval-then-outcome is a signal the writer cannot fabricate, and it is available in any system that can observe its own subsequent success or failure.

III

Utility is deflated by the number of memories tried

If a thousand memories are eligible and you keep the twenty that correlate with success, you have run a thousand-hypothesis experiment. The deflated Sharpe ratio [7] exists for exactly this situation in finance and transfers directly: the threshold a memory must clear rises with the size of the pool it was selected from. A memory store that does not track how many candidates it considered cannot know whether its best entries are real.

IV

Retrieval illuminates rather than optimises

Top-k nearest-neighbour retrieval is a pure optimiser, and optimisers collapse diversity. The quality-diversity literature [4] offers the alternative: partition the memory by behavioural descriptor — task type, outcome, recency, source — and return the best entry from each relevant cell rather than the k best overall. This is the same structure as a MAP-Elites archive, applied to recall, and it is what keeps a context window from filling with six restatements of one idea.

V

The substrate is readable without the model that wrote it

A memory keyed by one model's embedding vectors is that model's memory, not yours — swap the model and the index is meaningless. The durable substrate is text and explicit structure; embeddings are a disposable index built over it, per model, rebuildable at any time. This is the invariant that makes a store portable across a local 7B and a frontier API, and it costs nothing except the discipline of never treating the vector as the source of truth.

04The record

The invariants determine the schema more than any design preference does. Fields exist here because a failure mode demands them.

{
  // --- identity: stable, model-independent ---
  "id":         "sha256 of (artefact + context key)",
  "created":    "2026-09-16T15:04:49Z",
  "kind":       "procedure | fact | correction | preference",

  // --- I. ground truth. Never rewritten by any process. ---
  "artefact": {
    "source":   "command | file | api | human",
    "verbatim": "npm test -- --run  =>  exit 1, 3 failing",
    "locator":  "repo@a1b2c3d:package.json:14"
  },

  // --- the model's reading. Rewritable, marked as opinion. ---
  "interpretation": "vitest needs --run in CI or it hangs on watch mode",
  "written_by":     "any-model-id",

  // --- II. outcome, observed AFTER retrieval, by another process ---
  "uses":        41,
  "followed_by_success": 34,
  "last_used":   "2026-09-16T14:58:02Z",

  // --- III. the multiple-testing denominator ---
  "pool_size_at_write": 1180,   // candidates eligible that turn
  "deflated_utility":   0.71,   // corrected for the pool

  // --- IV. behavioural descriptor: the archive cell ---
  "cell": { "task":"build", "outcome":"fix", "scope":"repo" },

  // --- V. portable. Embeddings live elsewhere, per model. ---
  "text": "full record rendered as plain prose for any reader"
}
What makes this portable. Nothing above is a vector. A local model and a hosted model read the identical record; each may build its own index over text, and throwing that index away costs an afternoon of re-embedding rather than the memory itself. The id is a content hash rather than a database key, so two machines that observed the same artefact converge on the same identifier without coordinating.

05Scoring, concretely

Invariant III is the one most likely to be waved at and not implemented, so here it is as arithmetic. Let a memory be retrieved n times with k subsequent successes, drawn from a pool of N eligible candidates.

raw      = k / n                              // naive success rate
shrunk   = (k + 1) / (n + 2)                  // Beta(1,1) posterior mean
threshold= expected_max_of(N, n)              // what noise produces
utility  = shrunk - threshold                 // what is left over

expected_max_of(N, n) is the expected best success rate among N worthless memories each observed n times — the same order statistic the deflated Sharpe ratio uses, where the expected maximum over N independent trials grows like sqrt(2 ln N) in standard deviations. With N = 1,000 and n = 20, a memory needs a success rate roughly 0.20 above base rate before it has said anything. Most memories will not clear this. That is the finding, not a failure of the method.

The working system this synthesis was written against reports the same shape of result from the same correction: after 336,000 evaluated candidates, the deflation threshold rose faster than any candidate's measured edge, and the honest walk-forward returned t = 0.10. The correction is not conservative decoration. It is usually the answer.

06An evaluation that could falsify this

A design that cannot fail is not a design. The claim here is specific: grounded, deflated, illuminated memory outperforms confidence-written top-k memory on tasks where the model is confidently wrong, and is merely equal elsewhere. That is testable.

armdiffers by
A — baselinewrite on model confidence, retrieve top-k by embedding similarity
B — groundedA, plus invariant I: artefact preserved separately from interpretation
C — outcome-scoredB, plus invariant II: utility from post-retrieval outcome
D — deflatedC, plus invariant III: utility corrected for pool size
E — illuminatedD, plus invariant IV: per-cell retrieval instead of top-k

Run each arm across at least three model families — one local, two hosted — on a task suite with verifiable outcomes, because the survey's central empirical finding is that self-improvement "works where answers are checkable and degrades where they are not" [1]. Code and data tasks qualify; open-ended writing does not, and including it would produce a result nobody can audit.

Report, for every arm: success rate, and diversity of retrieved cells, and the fraction of retained memories whose deflated utility is positive. The middle metric is the one that catches diversity collapse, and it is the one a recall benchmark will never show you.

What would falsify the design. If arm E does not beat arm A on the confidently-wrong subset, invariants II–IV are decoration. If arm B alone captures most of the gain, then grounding is the whole story and the statistical machinery is over-engineering — a real possibility, and the cheapest outcome to act on. If every arm performs identically, the memory was never load-bearing and the honest report is that retrieval did not matter for this task suite.

07Limitations

The outcome signal is weak in exactly the cases you most want it. Invariant II requires observing what happened after retrieval, and attributing a downstream success to one retrieved memory among several is a credit-assignment problem this design does not solve. It reduces to a bandit over memories, with all of that machinery's sample-efficiency problems, and on rare tasks the posterior stays near its prior indefinitely.

Deflation makes a cold start slow by construction. Early on, N is small and the threshold is low, so weak memories clear it; later, the threshold rises and genuinely useful memories written early may fall below it. The store gets more conservative as it grows, which is correct and will feel wrong.

Behavioural cells are hand-designed. Invariant IV needs a descriptor space, and choosing it is the same unprincipled act as choosing MAP-Elites bins. Get it wrong and illumination degenerates into top-k with extra steps.

Portability is asserted, not proven. Invariant V makes the substrate readable by any model. It does not make it equally useful to any model — a 7B and a frontier model may need different granularity, and the same record may be too terse for one and redundant for the other. The evaluation above would detect this; nothing in the design prevents it.

08What this converges

The contribution is not a new algorithm. It is the observation that four literatures which do not cite each other are describing the same object from different sides:

fromcontributes
RSI survey [1]the failure taxonomy, and that the evaluator is the ceiling
Quality-diversity [4]illumination over optimisation — the fix for diversity collapse
Novelty search [5]objective deception: the thing you optimise can be what misleads you
Deflated Sharpe [7]selection bias has a closed form, and it is computable
AutoML-Zero [3]a primitive substrate outlasts the model searching over it

The last is the quiet one. AutoML-Zero's durable result was not the algorithms it found but that a sufficiently primitive representation survives its searcher. A memory of text and artefacts is primitive in the same sense. The models will be replaced — repeatedly, and faster than the memory should be — and a substrate that outlives them is worth more than one that retrieves marginally better this quarter.
